## 1. 🎮 Gamification & Rewards

### 1.1 ⭐ ระบบ Hearts / Points
**แนวคิด:** ทุกครั้งที่คุยกับ Character จะได้รับ "หัวใจ" หรือ "แต้มมิตรภาพ"

```
┌──────────────────────────────────────────────┐
│  🐰 KooJai                     ❤️ 156 Hearts │
│                                              │
│  "สวัสดีจ้า! วันนี้เป็นยังไงบ้าง?"             │
│                                              │
│        +3 ❤️ เพิ่งได้รับจากการคุย!            │
└──────────────────────────────────────────────┘
```

**รายละเอียด:**
- คุย 1 ครั้ง = +1-3 Hearts (สุ่ม)
- คุยติดต่อกันทุกวัน = Bonus Hearts
- Hearts สามารถใช้ปลดล็อคสิ่งต่างๆ

**ความยาก:** 🟡 ปานกลาง  
**ความน่าสนใจ:** ⭐⭐⭐⭐⭐

---

### 1.2 🏆 ระบบ Achievements / Badges
**แนวคิด:** ได้รับ Badge เมื่อทำกิจกรรมครบตามเงื่อนไข

**ตัวอย่าง Badges:**
| Badge | ชื่อ | เงื่อนไข |
|-------|------|---------|
| 🌟 | First Chat | คุยครั้งแรก |
| 💬 | Chatterbox | คุยครบ 50 ข้อความ |
| 🔥 | On Fire | คุยติดต่อกัน 7 วัน |
| 🌙 | Night Owl | คุยหลัง 4 ทุ่ม |
| 🌅 | Early Bird | คุยก่อน 7 โมงเช้า |
| 🎭 | Character Collector | สร้าง Character 3 ตัว |
| 🎤 | Voice Master | ใช้ Voice Mode 10 ครั้ง |
| 💝 | Best Friend | สะสม 500 Hearts กับ 1 Character |
| 🎨 | Designer | เปลี่ยน Theme 5 ครั้ง |
| 📖 | Storyteller | คุยเรื่องเดียวกันนานกว่า 30 ข้อความ |

**ความยาก:** 🟡 ปานกลาง  
**ความน่าสนใจ:** ⭐⭐⭐⭐⭐
